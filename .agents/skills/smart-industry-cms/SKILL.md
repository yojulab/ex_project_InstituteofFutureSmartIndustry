# Smart Industry CMS & Portal 컴포넌트 엔지니어링 가이드

미래스마트산업진흥원 안내 사이트의 공개 포털과 관리자 CMS 화면을 `docs/작업지시서.md` 규격에 맞추어 구현하는 표준 절차입니다.

---

## 1. 컴포넌트 개발 핵심 원칙

1. **Next.js App Router & Server Components 우선**:
   - 데이터 페칭과 SEO가 중요한 공개 페이지(소개, 사업, 알림, 자료실)는 React Server Component로 작성하여 클라이언트 번들 크기를 최소화한다.
   - 대화형 인터랙션(배너 제어, 탭 전환, 검색창, 관리자 폼)만 클라이언트 컴포넌트(`'use client'`)로 분리한다.
2. **사업 신청 기능 원천 배제**:
   - 사업안내 페이지에 온라인 신청/접수 폼, 접수 버튼을 일체 배치하지 않는다.
   - 정보 안내 전용 요약 카드(지원 대상, 기간, 상태, 담당부서)와 필요 시 외부 공식 링크(`target="_blank"`)만 제공한다.
3. **KWCAG 2.2 웹 접근성 필수 준수**:
   - 최상단 Skip Navigation(`[본문 바로가기]`, `[주메뉴 바로가기]`) 배치.
   - 모든 이미지 및 배너에 의미 있는 대체텍스트(`alt`) 제공. 관리자 등록 폼에서 `alt` 필수 검증.
   - 메인 배너 슬라이더에 [재생/일시정지] 버튼 제공 및 `prefers-reduced-motion` 대응.
   - 텍스트 명도 대비 4.5:1 이상 유지.

## 2. 화면별 구현 체크리스트

### 2-1. 공개 포털
- [ ] **메인 (`/`)**:
  - 공지 배너 (최대 3건, 재생/정지, "오늘 하루 열지 않음" localStorage)
  - 히어로 + 통합검색 (비전 문구, 검색창, 인기 검색어)
  - 빠른 메뉴 퀵링크 6종 (사업안내, 행사/교육, 자료실, FAQ, 오시는길, 문의)
  - 주요 사업 카드 4~6개 (접수중/예정/마감 상태 뱃지)
  - 새소식 탭 (전체/공지/보도/행사 탭 전환, 5건씩)
  - 자료실 하이라이트 (최신 3건)
- [ ] **소개 (`/about/*`)**:
  - 비전, 연혁, 조직도, 오시는 길 (지도 API 또는 약도)
- [ ] **사업안내 (`/programs`, `/programs/[slug]`)**:
  - 사업 목록 (분야/상태 필터링, 정렬)
  - 사업 상세 요약 카드 및 본문
- [ ] **알림마당 (`/news/*`) & 자료실 (`/resources/*`)**:
  - 키워드 검색, 카테고리 필터, 페이지네이션(10건)
  - 첨부파일 다운로드 아이콘, 형식/용량 표시

### 2-2. 관리자 CMS (`/admin/*`)
- [ ] **직접 로그인 (`/admin/login`)**:
  - 아이디 + 비밀번호 입력 폼
  - 5회 실패 잠금 안내 및 레이트리밋
  - 로그인 성공 시 HttpOnly 세션 쿠키 설정 및 `/admin/dashboard` 리다이렉트
- [ ] **콘텐츠 CRUD (`/admin/posts`, `/admin/programs`, `/admin/resources`)**:
  - 마크다운 에디터 + 실시간 프리뷰
  - 임시저장 / 즉시게시 / 예약게시 / 비공개 상태 관리
  - 저장 시 `revalidatePath` 호출로 공개 포털 온디맨드 ISR 캐시 무효화
- [ ] **배너/퀵링크 관리 (`/admin/banners`)**:
  - 이미지 업로드, 노출 기간, 정렬 순서
  - 대체텍스트(`alt`) 미입력 시 폼 제출 방지 validation
- [ ] **관리자 계정 관리 (`/admin/users`) & 감사로그 (`/admin/audit-logs`)**:
  - Admin 전용 권한 보호 (Editor 접근 시 403)
  - 감사로그 검색 및 페이징 (수정/삭제 버튼 없음)
