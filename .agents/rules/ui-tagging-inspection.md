# 미래스마트산업진흥원 — UI inspect 일련번호 태깅 및 원클릭 인스펙션 규격

본 문서는 의뢰자(기획자/클라이언트)와 AI 에이전트 간의 정밀한 UI 소통을 위해 **미래스마트산업진흥원 안내 사이트 및 관리자 CMS 전역에 적용되는 UI inspect 태깅 시스템**의 표준 규격을 정의한다.

---

## 1. UI inspect 일련번호 명명 체계 (Taxonomy)

화면 내 모든 주요 UI 요소는 고유한 일련번호(`data-serial-id`)를 부여받으며, 일관된 3단 계층 구조를 갖는다:

```text
[화면/메뉴 코드] - [섹션 코드] - [요소 약어 + 순번]
예시: P01-SEC02-SCH01, A00-NAV-POST01, A01-SEC01-BTN02
```

### 1-1. 화면 분류 코드 (Screen / Page Code)

| 구분 | 화면 코드 | 화면 명칭 및 주요 기능 |
| :--- | :--- | :--- |
| **공개 포털 공통** | `P00` | 상단 GNB 헤더, 유틸리티 바, 하단 푸터, 본문 건너뛰기 링크 |
| **메인 포털** | `P01` | 공지 배너, 히어로+검색, 퀵링크 6종, 주요 사업 카드, 새소식 탭, 자료실 |
| **진흥원 소개** | `P02` | 인사말·비전, 연혁, 조직·담당자 안내, 찾아오시는 길 |
| **사업안내** | `P03` | 지원사업 종합 목록, 카테고리 필터, 사업 상세 안내 (신청 폼 배제) |
| **알림마당** | `P04` | 공지사항, 보도자료, 행사·교육, 입찰공고 목록 및 상세 |
| **자료실** | `P05` | 간행물·보고서, 통계·동향, 법령·규정 자료 목록 및 다운로드 |
| **이용안내** | `P06` | 자주 묻는 질문(FAQ), 문의처 안내, 사이트맵 |
| **통합검색** | `P07` | On-Device 키워드·의미 통합검색 결과 화면 |
| **관리자 공통** | `A00` | 관리자 좌측 사이드바 네비게이션, 사용자 정보, 로그아웃 |
| **관리자 로그인** | `A01` | 직접 로그인 폼 (`/admin/login`), 계정 식별자/비밀번호 입력 |
| **관리자 대시보드**| `A02` | 종합 운영 현황 통계, 퀵 액션, 최근 감사로그 |
| **게시물 관리** | `A03` | 알림마당 게시물 CRUD, 마크다운 에디터, 발행 관리 |
| **사업안내 관리** | `A04` | 진흥원 지원사업 공고 마스터 CRUD 및 상태 제어 |
| **자료실 관리** | `A05` | 발간물·통계·법령 자료 및 첨부파일 등록 관리 |
| **FAQ 관리** | `A06` | 자주 묻는 질문 항목 CRUD 및 노출 순서 관리 |
| **배너/링크 관리** | `A07` | 상단 롤링 공지 배너 및 퀵링크 등록 (대체텍스트 alt 필수) |
| **계정 관리** | `A08` | 관리자 계정 생성, 권한 부여, 5회 실패 잠금 해제 |
| **보안 감사로그** | `A09` | 관리자 활동 및 시스템 보안 감사로그 조회 |

### 1-2. 섹션 및 요소 약어 규격 (Section & Element Tag)

| 섹션/요소 | 접두사 | 예시 및 설명 |
| :--- | :--- | :--- |
| **섹션 (Section)** | `SEC01~99` | `SEC01-BNR`(배너), `SEC02-SCH`(검색), `SEC03-QCK`(퀵링크), `SEC04-PRG`(사업) |
| **네비게이션** | `NAV` | `NAV-DASH`(대시보드), `NAV-POST`(게시물관리), `NAV-USER`(사용자정보) |
| **버튼 (Button)** | `BTN` | `BTN01`(로그인), `BTN02`(비밀번호보기), `BTN-MORE`(더보기) |
| **입력창 (Input)** | `INP` | `INP01`(아이디/이메일), `INP02`(비밀번호), `INP-SCH`(검색창) |
| **카드 (Card)** | `CRD` | `CRD01`(사업안내 카드), `CRD02`(자료실 카드) |

## 2. UI inspect 동작 및 시각 스타일 규격

`docs/UI-inspects.md` 표준 규격에 따라 4대 개선 사항이 엄격히 적용된다:

### 2-1. 단축키 및 FAB 토글
- **전역 단축키**: **`Alt + I`** 또는 **`Ctrl + Shift + T`**
- **플로팅 버튼(FAB)**: 화면 우측 하단 고정 플로팅 버튼 제공
  - 기본 상태 라벨: `🏷️ UI inspect (Alt+I)`
  - 활성화 상태 라벨: `🏷️ UI inspect ON (Alt+I)`
  - 툴팁 (Title): `단축키 Alt+I 로 UI inspect 모드를 켜고 끌 수 있습니다`
  - URL 파라미터 지원: `?inspect=1` 진입 시 초기 로딩부터 자동 활성화

### 2-2. 뱃지 시각 스타일 (1단계 축소 콤팩트 규격)
- **위치**: 요소 좌상단(Top-Left) 핀 고정 (`top: -8px; left: -2px;`)
- **관리자 사이드바 메뉴**: 타 뱃지와 일관되게 좌상단 핀 고정 (`top: -6px !important; left: 8px !important;`)
- **사이즈**:
  - 폰트: `9.5px`, `font-weight: 700`, monospace
  - 패딩: `2.5px 5.5px`
  - 모서리 곡률: `border-radius: 4px`
  - 배경: `linear-gradient(135deg, #3182F6 0%, #6366F1 100%)` (토스 블루 & 인디고)
  - 텍스트 컬러: `#ffffff`
  - 박스 섀도우: `0 2px 8px rgba(49, 130, 246, 0.4), 0 0 0 1px rgba(255, 255, 255, 0.2)`
- **마우스 호버**: 스케일 1.12배 확대 및 딥 블루 색상 전환
- **복사 완료 피드백**: 1.2초간 에메랄드 그린(`background: #10B981 !important;`) 전환 및 `Copied! ✓` 표시

### 2-3. 원클릭 클립보드 4대 필수 정보 복사
일련번호 뱃지를 클릭하면 클립보드에 아래 4대 필수 정보가 자동 복사된다:
```text
- 일련번호: P01-SEC02-SCH01
- 페이지명: 미래스마트산업진흥원 — 대한민국 제조 AI 및 스마트산업 혁신 선도
- URI: http://localhost:30013/
- 항목명: 누리집 통합검색 입력창
```
동시에 하단 중앙에 토스트 알림이 표시된다:
`📋 [P01-SEC02-SCH01] 4대 정보 복사 완료! (일련번호/페이지/URI/항목명)`

## 3. 에이전트 협업 가이드라인

1. **Portal UI Engineer**:
   - 공개 포털 헤더, 메인 홈 컴포넌트, 사업/알림/자료실 화면 컴포넌트 마크업 시 주요 인터랙션 요소 및 컨테이너에 `<UiBadge id="Pxx-..." name="..." />` 또는 `.ui-serial-badge` 요소를 배치한다.
   - 뱃지가 포함되는 부모 컨테이너에 `relative` 포지셔닝을 보장하여 뱃지 위치가 올바르게 고정되도록 한다.
2. **Admin CMS Engineer**:
   - 관리자 사이드바 네비게이션, 대시보드 통계 카드, 로그인 폼 등에 `Axx-...` 규격의 뱃지를 배치한다.
3. **QA & Security Critic**:
   - 화면 검증 시 `Alt+I`로 UI inspect 모드를 활성화한 상태에서 스크린샷을 검수하고, 일련번호가 올바르게 부여되었는지 확인한다.
