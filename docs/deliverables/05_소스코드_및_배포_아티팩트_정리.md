## 2. 확정 기술 스택 명세

- **Core Framework**: React 19 + Next.js 16.4.0 (App Router, Turbopack)
- **Language**: TypeScript 5 (Strict Mode)
- **Styling**: Tailwind CSS 4 + Lucide React Icons
- **Database & ODM**: MongoDB (GCP Compute Engine 자체 운영) + Mongoose 8
- **Authentication**: Argon2id / bcrypt 해싱 + jose JWT + HttpOnly/Secure 세션 쿠키
- **Mail System**: Nodemailer (SMTP 표준 프로토콜)
- **Markdown & Security**: ReactMarkdown + remark-gfm + rehype-sanitize (XSS 살균)
- **SEO & Social**: Next.js Metadata API + dynamic ImageResponse (OG Image)

## 4. 빌드 및 배포 아티팩트

- **빌드 명령어**: `npm run build` (Next.js 정적 최적화 및 서버 번들 컴파일)
- **프로덕션 구동**: `npm run start` (기본 포트 30013 / Cloud Run PORT 환경변수 연동)
- **컨테이너 이미지**: Google Cloud Artifact Registry 등록용 경량화 Dockerfile
- **아티팩트 무결성**: 17개 라우트 전체 컴파일 성공, `tsc --noEmit` 에러 0건 확인 완료.
