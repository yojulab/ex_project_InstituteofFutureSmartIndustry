# 노션 MD 파서 및 XSS 살균 테스트 보고서

- **문서 번호:** FSIPI-DELIV-20261030-11
- **프로젝트명:** 미래스마트산업진흥원 홈페이지 구축 (온라인 강좌 시스템)
- **발행 일자:** 2026년 10월 30일
- **적용 기술:** `react-markdown` 10.x, `remark-gfm` 4.x, `rehype-sanitize` 6.x

---

## 1. 개요 및 보안 기준

강사가 노션에서 작성하여 내보낸 마크다운(`.md`) 파일에는 악성 자바스크립트나 인라인 태그가 포함될 잠재적 위험이 있습니다. 본 시스템은 **Zero-Tolerance 보안 원칙**에 따라 HAST 기반 AST 화이트리스트 필터링인 `rehype-sanitize`를 강제 적용하여 악성 스크립트를 원천 무력화합니다.

## 2. XSS 공격 페이로드 살균 테스트 결과 (LAC-10)

| 번호 | 공격 벡터 | 테스트 입력 페이로드 | 살균 결과 | 판정 |
| :---: | :--- | :--- | :--- | :---: |
| 1 | 인라인 스크립트 | `<script>alert('xss')</script>` | 태그 완전 제거 (텍스트 미실행) | **PASS** |
| 2 | 이미지 onerror | `<img src="x" onerror="alert(1)">` | onerror 이벤트 핸들러 제거 | **PASS** |
| 3 | javascript: 링크 | `[악성링크](javascript:stealCookie())` | href 속성 무력화 또는 제거 | **PASS** |
| 4 | iframe 피싱 | `<iframe src="https://evil.com"></iframe>` | iframe 태그 완전 차단 | **PASS** |
| 5 | SVG 온로드 | `<svg onload="alert(1)">` | SVG 태그 및 onload 제거 | **PASS** |
| 6 | 본문 직접 주입 | `dangerouslySetInnerHTML` 코드 검사 | 코드베이스 내 직접 바인딩 0건 확인 | **PASS** |

## 3. 노션 마크다운 렌더링 품질 검증 (LAC-09)

1. **GitHub Flavored Markdown (GFM) 지원:**
   - H1 ~ H4 헤더 스타일링 계층 구조 유지 확인.
   - 불릿 목록, 번호 매기기 목록, 인용구(`>`) 좌측 보더 스타일 확인.
   - 체크박스 할 일 목록(`- [x]`) 렌더링 확인.
2. **반응형 테이블(Table):**
   - 모바일(375px) 화면에서도 테이블이 화면을 벗어나 깨지지 않고, 가로 스크롤 컨테이너(`overflow-x-auto`) 내에서 안전하게 스크롤됨을 확인.
3. **코드 블록 및 인라인 코드:**
   - 배경색 `bg-slate-950`, 글자색 `text-slate-100` 및 monospace 폰트 적용 확인.
4. **Sticky TOC 목차:**
   - 본문 내 H2, H3 태그를 파싱하여 데스크톱 우측에 스티키 목차를 자동 생성하고, 클릭 시 해당 섹션으로 스무스 스크롤 이동함을 확인.
