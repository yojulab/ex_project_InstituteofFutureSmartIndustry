## 2. 화면별 3단 반응형 UI 레이아웃 상세 명세

### 2-1. 메인 화면 [P-01] (`/`)

1. **히어로 섹션**:
   - **데스크톱 (1440px)**: 좌측 공식 지정 슬로건("대한민국 미래를 여는 스마트 제조와 AI 혁신의 중심"), 우측 진흥원 핵심 4대 가치 뱃지 및 배경 그라디언트 배치.
   - **태블릿 (768px)**: 중앙 정렬 타이포그래피, 하단 퀵 링크 버튼 가로 2열 배치.
   - **모바일 (375px)**: 타이틀 2줄 줄바꿈 최적화(`text-2xl`), CTA 버튼 100% 전폭 배치.
2. **주요사업 4대 카드 섹션**:
   - **데스크톱**: 4열 가로 그리드(`grid-cols-4`), 호버 시 미세 상승 효과(`-translate-y-1.5`).
   - **태블릿**: 2열 그리드(`grid-cols-2`).
   - **모바일**: 1열 스택(`grid-cols-1`), 카드 간 여백 16px 최적화.
3. **주요 성과 및 활동 3선 섹션**:
   - **데스크톱**: 최대 3건 3열 카드 배치(`grid-cols-3`), 썸네일 16:9 비율 유지.
   - **모바일**: 1열 카드 스택, 썸네일 상단 배치, 글자 크기 축소(`text-sm`).
   - **예외 처리**: 등록된 승인 게시물이 0건일 때 섹션 전체 DOM 자동 숨김(`return null`).
4. **초대 원장 프로필 요약 섹션**:
   - **데스크톱**: 좌측 원장 이모지/사진 카드(w-44), 우측 25년 경력 타임라인 및 분리 안내문.
   - **모바일**: 상단 원장 카드 중앙 정렬, 하단 약력 목록 배치.
5. **협력 문의 배너 섹션 및 푸터**:
   - **데스크톱**: 좌우 2분할 레이아웃, 푸터 3열 정보(정책링크 / 기관정보 / 인증마크).
   - **모바일**: 1열 수직 정렬, 패밀리사이트 셀렉트 박스 100% 전폭 확장.

## 3. 웹 접근성(KWCAG 2.2) 검증 결과

1. **포커스 링 (Focus Ring)**: 모든 대화형 요소(버튼, 링크, 인풋)에 `focus:ring-2 focus:ring-sky-500` 적용.
2. **명도 대비 (Color Contrast)**: 텍스트 및 핵심 UI 요소의 명암비가 최소 4.5:1 이상(본문 7.2:1) 유지.
3. **대체 텍스트**: 모든 `<img>` 및 아이콘에 의미 있는 `alt` 및 `aria-hidden` 속성 지정.
