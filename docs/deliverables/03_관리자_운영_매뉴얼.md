# 미래스마트산업진흥원 관리자 CMS 운영 매뉴얼 (03)

- **문서 번호**: FSIPI-DELIV-20261026-03
- **프로젝트명**: 미래스마트산업진흥원 홈페이지 통합 구축 (MVP v3.0)
- **작성일자**: 2026년 10월 26일
- **대상 독자**: 비영리법인 운영 담당자, 콘텐츠 편집자, 시스템 최고관리자

---

## 1. 관리자 시스템 접속 및 인증 (ADM-01)

### 1-1. 접속 주소 및 식별자
- **관리자 접속 URL**: `https://smartindustry.or.kr/admin/login` (또는 포털 하단 링크 배제형 비공개 URL)
- **로그인 식별자**: 사용자 아이디(`username`) 또는 등록된 공식 이메일(`email`) 모두 지원.

### 1-2. 보안 인증 및 계정 잠금 정책 (가드레일 준수)
1. **패스워드 암호화**: 최신 Argon2id / bcrypt 해싱 적용 (평문 저장 0건).
2. **5회 연속 실패 시 계정 잠금**:
   - 비밀번호를 5회 연속 잘못 입력하면 해당 계정은 보안을 위해 **15분간 자동으로 로그인 차단**됩니다.
   - 잠금 해제는 15분 경과 후 자동 해제되거나, 최고관리자 계정(`/admin/users`)에서 수동으로 초기화할 수 있습니다.
3. **세션 쿠키 격리**:
   - `HttpOnly`, `Secure`, `SameSite=Strict` 속성이 부여된 보안 JWT 토큰으로 유지되며, 8시간 동안 활동이 없으면 자동 로그아웃됩니다.

## 2. 통합 게시물 관리 (ADM-02)

### 2-1. 게시물 목록 조회 및 필터링 (`/admin/posts`)
- **분류 필터**: 전체 / 공지사항 / 기관활동 / 학술논문 / 원장활동
- **상태 필터**: 전체 / 공개(public) / 임시저장(draft) / 비공개(private)
- **제목 검색**: 키워드를 입력하여 즉시 실시간 필터링 가능.

### 2-2. 메인 화면 [주요 성과 및 활동] 노출 제어 (AC-07)
1. **메인 노출 한도**: 최대 **3건**까지만 지정 가능합니다.
2. **원클릭 토글**:
   - 목록에서 노란색 별표(★)를 클릭하여 즉시 메인 노출 상태를 켜거나 끌 수 있습니다.
   - **4번째 게시물 노출 지정 시도 시**: 서버에서 `409 Conflict`를 반환하며, *"메인 노출 게시물은 최대 3건까지만 지정할 수 있습니다"* 경고창이 나타납니다. 기존 게시물을 먼저 해제해야 새 게시물을 지정할 수 있습니다.
3. **0건 처리**: 메인 노출 승인 게시물이 0건인 경우 메인 화면의 [주요 성과] 섹션은 화면에 아예 나타나지 않습니다(공백 방지).

### 2-3. 신규 게시물 작성 및 수정 (`/admin/posts/new`, `/admin/posts/[id]/edit`)
1. **기본 메타데이터**:
   - **분류 구분**: 공지사항, 기관활동, 학술논문, 원장활동 중 택일.
   - **게시 상태**: 공개(즉시 포털 노출), 임시저장(작성 중), 비공개(포털 404 차단).
   - **행사/발행 일시**: 실제 세미나/콘퍼런스 날짜 또는 논문 발행일 지정.
   - **제목 및 슬러그**: 슬러그는 영문 소문자, 숫자, 하이픈(-)으로 구성되며 포털 URL(`/updates/[slug]`)이 됩니다.
2. **카테고리별 특화 필드**:
   - **학술논문 (`paper`) 선택 시**: 저자 목록(쉼표 구분), 게재 학술지명, 권·호·페이지, 공식 DOI 링크(`https://doi.org/...`) 입력.
   - **기관활동/원장활동 (`activity`, `director`) 선택 시**: 출처 언론사명, 원문 기사 링크 URL 입력.
3. **썸네일 이미지 및 대체 텍스트(alt) 필수 정책 (AC-14)**:
   - 썸네일 이미지 URL을 입력할 경우 시각장애인을 위한 **대체 텍스트(`alt`) 입력이 필수**로 강제됩니다. alt가 비어있으면 저장이 차단됩니다.
4. **마크다운 편집기 및 실시간 살균 미리보기**:
   - 편집기 탭에서 `# 제목`, `**굵게**`, `- 목록` 등의 마크다운을 입력합니다.
   - [미리보기] 탭을 클릭하면 악성 스크립트가 자동 살균(`rehype-sanitize`)된 최종 렌더링 화면을 실시간 확인할 수 있습니다.

## 3. 관리자 계정 관리 (`/admin/users`)

- **접근 권한**: 최고관리자(`admin`) 권한을 가진 계정만 접근 가능.
- **계정 현황**: 등록된 관리자 목록, 권한(admin/editor), 로그인 실패 횟수 및 계정 잠금 상태 확인.

---

## 4. 보안 감사로그 확인 (`/admin/audit-logs`)

- **기록 대상**:
  - 관리자 로그인 성공 및 실패 (IP 및 시간 기록)
  - 게시물 등록(`CREATE`), 수정(`UPDATE`), 삭제(`DELETE`)
  - 메인 노출 토글 이력
- **보안 무결성**: 감사로그는 수정 및 삭제가 불가능한 불변(Append-Only) 원장으로 보관됩니다.
