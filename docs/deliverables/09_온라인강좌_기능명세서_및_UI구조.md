## 1. 개요 및 시스템 목적

본 시스템은 미래스마트산업진흥원이 단순한 기관 소개 사이트에 머무르지 않고, **실제 교육·연구 활동이 역동적으로 운영되고 있음을 대외적으로 증명**하기 위해 구축된 **온라인 강좌 및 강의 자료 아카이브 시스템**입니다.

### 1-1. 핵심 기술 방향성 준수
1. **자체 스트리밍 인프라 배제 (비용 0원 수렴):** 유튜브(전체/일부공개) 소스를 활용하여 대용량 비디오 호스팅 및 트래픽 비용을 완전 무료화.
2. **KOCW형 차시별 강의 재생 UI:** 상단 16:9 반응형 유튜브 플레이어 + 하단 차시별 목록 테이블 구조로, 페이지 새로고침 없는 즉각적인 영상 전환 인터랙션 구현.
3. **노션(Notion) 마크다운 및 교재 뷰어:** 강사가 작성한 `.md` 파일을 웹에 미려하게 렌더링하며, Sticky TOC 목차 및 PDF 인라인 미리보기 지원.
4. **엄격한 가드레일 준수:** 외부 상용 LLM 유출 0건 격리, 회원가입/자유게시판 배제, 관리자 권한 전용 메인 노출 제어(Q6), 50MB 교재 파일 5MB 청크 분할 업로드.

## 2. 화면별 기능 명세 및 UI 구조

### 2-1. [P-09] 온라인 강좌 목록 (`/lectures`)
- **카테고리 탭 (5종):** `전체`, `인공지능·IT`, `스마트뷰티·미용`, `직업교육·자격`, `기타`
- **강좌 형태 필터 (3종):** `전체 형태`, `동영상 강좌 (KOCW형)`, `텍스트 강좌 (노션MD)`
- **강좌 내 키워드 검색:** MongoDB `$text` 텍스트 인덱스를 활용한 강좌명, 강사명, 본문 키워드 검색. (전역 검색창 배제 가드레일 준수)
- **강좌 카드 그리드 (PC 3열 / 태블릿 2열 / 모바일 1열):**
  - 16:9 썸네일 이미지 및 마우스 호버 시 부드러운 확대 (`hover:scale-[1.02]`)
  - 강좌 유형 배지: `동영상 N차시` (파란색) 또는 `강의노트/MD` (초록색)
  - 분야 카테고리 배지, 강좌명(최대 2줄 말줄임), 담당 강사진, 수강하기 링크
- **Empty State:** 조건 만족 강좌가 없을 시 "등록된 강좌가 없습니다." 및 초기화 버튼 표출.

### 2-2. [P-10] KOCW형 차시별 동영상 강좌 상세 (`/lectures/:slug`)
- **상단 16:9 반응형 유튜브 플레이어:**
  - 중앙 정렬(`max-width: 1000px; aspect-ratio: 16 / 9;`), 도메인 `www.youtube-nocookie.com` 적용.
  - 파라미터 `rel=0`, `modestbranding=1`, `enablejsapi=1` 적용.
- **플레이어 직하단 차시 내비게이션 바:**
  - 현재 재생 중인 차시 제목 표시 (예: *"제 01-1차시. 강의 오리엔테이션 및 AI 기초 개요"*)
  - `[이전 차시]`, `[다음 차시]` 버튼 (첫/끝 차시 비활성화 처리)
- **하단 3대 탭 메뉴:**
  1. **차시별 강의 목록:** 차시 번호, 강의명, 강의시간, 수강하기/재생중 배지. 클릭 시 **페이지 새로고침 없이 상단 플레이어 영상 즉각 교체**.
  2. **강의 계획 및 소개:** 강좌 개요, 목표 및 안내사항.
  3. **강의 자료:** 등록된 PDF, PPTX 교재 다운로드 및 PDF 인라인 미리보기.
- **타인 공유 목적 딥링크 (Q5):**
  - `?ep=N` 차시 딥링크를 지원하여 특정 차시로 직접 진입 가능.
  - [이 차시 링크 복사], [강좌 링크 복사], 모바일 Web Share API 연동.

### 2-3. [P-11] 노션 MD 텍스트 강좌 상세 (`/lectures/note/:slug`)
- **마크다운 렌더러:** ReactMarkdown + GFM(GitHub Flavored Markdown) 스타일링.
- **구문 강조 및 보안:** `rehype-sanitize` XSS 살균 방어 및 코드블록 복사 지원.
- **표(Table):** 모바일에서도 깨지지 않는 가로 스크롤 컨테이너 지원.
- **이미지 라이트박스:** 본문 이미지 클릭 시 전체 화면 라이트박스 뷰어 제공.
- **Sticky TOC 목차:** 본문 내 H2, H3 헤더를 자동 감지하여 우측에 스티키 목차 생성 및 클릭 시 부드러운 스크롤 이동(Scrollspy).

### 2-4. [ADM-03, ADM-04] 관리자 강좌 CMS (`/admin/lectures`)
- **강좌 목록 관리:** 강좌 조회, 공개/비공개/임시저장 토글, 삭제 처리.
- **메인 노출 강좌 제어 (Q6):** 관리자 권한 전용 토글, 서버 3건 초과 방어(409 Conflict) 검증.
- **동영상 차시 등록기:** 동적 행 추가/삭제, 유튜브 URL 입력 즉시 Video ID 정규화 미리보기, 위/아래 순서 이동.
- **노션 MD 업로더:** `.md` 파일 드래그앤드롭 로드, 실시간 미리보기, 상대경로 이미지 누락 감지 경고 배너.
- **50MB 교재 첨부:** 5MB 청크 분할 업로드 및 진행률 프로그레스 바.
