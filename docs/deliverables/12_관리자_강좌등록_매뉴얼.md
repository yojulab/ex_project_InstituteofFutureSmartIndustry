# 관리자용 온라인 강좌 등록 및 운영 매뉴얼

- **문서 번호:** FSIPI-DELIV-20261030-12
- **프로젝트명:** 미래스마트산업진흥원 홈페이지 구축 (온라인 강좌 시스템)
- **대상 사용자:** 미래스마트산업진흥원 홈페이지 운영자 및 콘텐츠 관리자
- **관리자 접속 경로:** `https://smartindustry.or.kr/admin/lectures` (비공개 관리자 로그인 필요)
- **발행 일자:** 2026년 10월 30일

---

## 1. 개요 및 화면 안내

온라인 강좌 관리 메뉴는 운영자가 **동영상 강좌(KOCW형)** 또는 **텍스트 강좌(노션MD)**를 등록·수정·삭제하고, 메인 포털 화면에 추천 강좌(최대 3건)를 지정하는 백오피스 시스템입니다.

---

## 2. 신규 강좌 등록 단계별 가이드

### 2-1. 기본 정보 입력
1. 관리자 좌측 사이드바에서 **[온라인 강좌 관리]** 클릭 후 상단 **[+ 신규 강좌 등록]** 버튼을 클릭합니다.
2. **강좌 유형 선택:**
   - `[동영상 강좌 (유튜브/KOCW형)]`: 차시별 유튜브 영상을 등록하는 강좌.
   - `[텍스트 강좌 (노션 마크다운 MD형)]`: 노션에서 작성한 글을 등록하는 강좌.
3. **강좌명 (제목):** 수강생에게 노출될 공식 강좌명을 입력합니다.
4. **슬러그 (URL 식별자):** 주소창에 표시될 고유 영문 식별자를 입력합니다 (예: `ai-prompt-engineering`).
   - *팁: 추후 슬러그를 변경하더라도, 기존에 공유된 링크로 들어온 사용자는 최신 슬러그로 자동 연결(301 리디렉션)되므로 안심하고 수정하실 수 있습니다.*
5. **분야 카테고리:** `인공지능·IT`, `스마트뷰티·미용`, `직업교육·자격`, `기타` 중 선택합니다.
6. **대표 썸네일:**
   - 동영상 강좌의 경우 `YouTube 첫 번째 영상 썸네일 자동 추출` 체크박스를 체크하면 첫 영상의 고화질 썸네일이 자동 적용됩니다.
   - 대체 텍스트(alt)는 시각장애인 접근성을 위해 반드시 입력해야 합니다.

---

### 2-2. 동영상 강좌 차시 등록 (동영상 유형 선택 시)
1. **[+ 차시 추가]** 버튼을 클릭하여 원하는 만큼 차시 행을 생성합니다.
2. **유튜브 URL 입력:**
   - 표준 주소(`https://www.youtube.com/watch?v=...`), 공유 축약 주소(`https://youtu.be/...`), 쇼츠/라이브 주소, 또는 11자리 고유 ID 중 어떤 것을 복사해 붙여넣어도 시스템이 자동으로 11자리 비디오 ID를 추출합니다.
   - 올바른 주소 입력 시 `[추출된 ID: ...]` 녹색 배지가 표출됩니다.
3. **차시 순서 변경:**
   - 우측의 `[위로 이동]`, `[아래로 이동]` 화살표 버튼을 클릭하여 차시 순서를 손쉽게 바꿀 수 있습니다. 차시 번호는 자동으로 1, 2, 3... 순서대로 재정렬됩니다.

---

### 2-3. 노션 마크다운(MD) 업로드 (텍스트 유형 선택 시)
1. 노션(Notion)에서 작성한 강의 페이지 우측 상단 `[...]` -> `[내보내기]` -> 형식을 `[Markdown 및 CSV]`로 선택하여 다운로드합니다.
2. 관리자 화면의 **[.md 파일 불러오기]** 버튼을 눌러 다운로드한 `.md` 파일을 선택하면 본문 에디터에 즉시 텍스트가 로드됩니다.
3. **이미지 첨부:**
   - 본문에 들어갈 이미지는 상단의 **[이미지 첨부]** 버튼을 통해 업로드합니다. 업로드 완료 시 본문 커서 위치에 `![파일명](이미지URL)` 코드가 자동 삽입됩니다.
   - 노션의 상대경로 이미지가 남아있는 경우 화면 상단에 경고 배너가 표시되므로 쉽게 확인하고 교체하실 수 있습니다.
4. **[미리보기] 탭:** 상단 탭을 전환하여 실제 웹사이트에 어떻게 표시되는지 실시간으로 확인하실 수 있습니다.

---

### 2-4. 강의 교재 및 실습자료 첨부 (최대 50MB)
1. 하단 **[교재 첨부]** 영역에 PDF, PPTX, ZIP 교재 파일을 끌어다 놓거나 선택합니다.
2. 50MB 대용량 파일도 5MB 단위로 자동 분할 전송되어 네트워크 끊김 없이 안정적으로 업로드됩니다.
3. 등록된 PDF 파일은 수강생이 웹 브라우저에서 즉시 인라인으로 열람할 수 있는 미리보기 뷰어를 제공합니다.

---

### 2-5. 메인 포털 추천 강좌 지정 (Q6)
- **메인 화면 추천 노출 체크박스:**
  - 메인 포털 첫 화면에 하이라이트로 노출할 강좌는 **최대 3건**까지 지정할 수 있습니다.
  - 3건을 초과하여 지정할 경우 시스템이 자동으로 방어 안내를 표시하므로, 기존 노출 강좌를 먼저 해제하신 후 새로 지정하시면 됩니다.
  - 추천 강좌로 지정된 강좌가 0건일 경우 메인 포털의 추천 강좌 섹션은 자동으로 완전히 숨겨져 깔끔한 공공 포털 품질을 유지합니다.
