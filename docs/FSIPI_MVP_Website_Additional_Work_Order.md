## 1. 개요 및 작업 배경

본 작업 지시서는 2026년 10월 25일 확정된 **「미래스마트산업진흥원 홈페이지 통합 구축 기획안 v3.0」**에 근거하여, 현재 구축된 임시/테스트 웹사이트(기존 URL: `https://fifth.axfoundly.com/about/vision` 등)의 문제점을 시정하고 공식 MVP 홈페이지로 완성하기 위해 개발사가 즉각 이행해야 할 **구체적 작업 내역과 검수 기준**을 정의합니다.

### 1.1 핵심 개편 방향
1. **MVP 범위 준수 (비필수 기능 전면 제거):** 회원가입, 결제, 자격증 접수/발급, 챗봇, 슬라이더 등 불필요한 기능을 완전 배제하고, 핵심 정보 제공과 문의 기능에 집중합니다.
2. **법적·행정적 리스크 방지 (임의 정보 전면 삭제):** 미래스마트산업연구소의 사업자번호/실적 도용 금지, 민간자격 '준비' 명시, 원장 개인 실적과 기관 실적 분리 등 표시 투명성을 확보합니다.
3. **단일 정보구조 일원화:** 분산되어 있던 게시판을 '통합 게시판 1개'로 통합하고, GNB를 4개 메뉴로 정리합니다.
4. **운영 환경 이관 및 자산 인계:** 실운영 서버 도메인 이관, 관리자 계정 생성, 소스코드 및 데이터 백업/복구 절차를 완비합니다.

### 4.2 [P-02] 진흥원 소개 (`/about`)
- 비영리 목적의 공익성과 공공성을 명확히 전달.
- **정관 열람:** 개인정보(발기인 명부, 서명, 주민번호 등)가 완벽히 마스킹/제외된 **‘공개용 정관 PDF’** 1개 링크를 제공하여 새 탭에서 열람 또는 다운로드되도록 구현.
- 원장 소개 링크 버튼 제공 (`/about/director`).
- 승인되지 않은 법적 지위(인가 전 사단법인 표기 등)를 단정적으로 표현하지 말 것.

### 4.3 [P-03] 원장 소개 (`/about/director`)
- 사진: 권리가 확보된 정식 프로필 사진 사용.
- 학력: 박사과정 및 수료 여부를 사실대로 표기 (박사학위 취득으로 오인되지 않도록 기재).
- 실무 및 연구 경력: 25년 이상의 실무/교육 경력을 일목요연하게 타임라인 또는 리스트 형태로 구성.
- 학술 성과 링크: 아래의 근거 논문 정보를 정확히 표기하고 원문 링크(DOI) 연결.
  - 논문 1: 김범준(2026), 「정보기술 직업교육 전문가들의 사이버보안 인식과 방향성 탐색」, 『융합과 통섭』 9(5), 309–325. (DOI: `https://doi.org/10.33090/SFCC.9.5.18`)
  - 논문 2: 김범준·김찬선(2025), 「생성형 인공지능 시대, IT산업의 윤리적 방향성 탐색: 저작권의 딜레마」, 『융합과 통섭』 8(5), 112–130. (DOI: `https://doi.org/10.33090/SFCC.8.5.8`)

### 4.4 [P-04] 주요사업 (`/business`)
- 4개 사업 영역을 1개의 단일 페이지 내에서 4개 앵커 섹션(`id="tech"`, `id="qualification"`, `id="edu"`, `id="research"`)으로 구현.
- **민간자격 섹션 제약사항:**
  - 제목 옆에 **[준비 중]** 상태를 명시.
  - "향후 국가공인 및 민간자격 기준에 맞추어 표준 교육체계를 연구·기획 중입니다"라는 안내만 제공.
  - **접수하기, 시험 일정, 응시료 결제, 자격증 신청 등의 버튼/링크 생성 엄격 금지.**
- 각 사업 섹션 하단에 `사업 협력 문의하기` 버튼 배치 (`/contact?type=coop` 등으로 연동).

### 4.5 [P-05] 소식·성과 (`/updates`)
- 상단 탭 필터: `전체` | `공지사항` | `기관 활동/보도` | `학술논문` | `원장 대외활동`
- 리스트 아이템: 썸네일(선택), 카테고리 태그, 제목, 요약문, 실제 발생일/발표일, 등록일.
- 페이지네이션 제공 (게시물 수가 적을 경우 기본 1페이지 표시).
- **데이터가 없을 경우:** "등록된 게시물이 없습니다." 안내 문구 출력 (가상 데이터 금지).

### 4.6 [P-06] 게시물 상세 (`/updates/:id`)
- 카테고리 뱃지, 제목, 등록일자, 실제 행사/논문 발표일자 표기.
- 학술논문의 경우 DOI 링크, 저자, 학술지명 등 메타데이터 필드 출력.
- 기사/보도의 경우 허가받지 않은 원문 전체 복제 금지 (3~4줄 요약문 + 원본 언론사 기사 링크).
- 하단에 `목록으로 돌아가기` 버튼 제공.
- 유효하지 않은 ID 또는 비공개 글 접근 시 정상적인 안내(404 Not Found 또는 비공개 알림) 페이지 노출.

### 4.7 [P-07] 문의하기 (`/contact`)
- **폼 입력 필드:**
  - 성명 / 담당자명 (필수, Text)
  - 이메일 주소 (필수, Email 포맷 검증)
  - 문의 유형 (필수, Radio 또는 Select: `기관 및 사업 협력` / `전문 교육 문의` / `일반 문의`)
  - 소속 기관/기업명 (선택, Text)
  - 문의 내용 (필수, Textarea, 최소 10자 이상)
  - 개인정보 수집 및 이용 동의 체크박스 (필수, 개인정보처리방침 요약 링크 포함)
- **전송 프로세스:**
  - 클라이언트 입력값 유효성 검증 + 서버 사이드 검증.
  - 봇 스팸 방지: Honeypot 필드 또는 간이 캡차(reCAPTCHA / Turnstile 등) 적용.
  - 지정된 진흥원 공식 수신 이메일로 SMTP 발송 처리.
  - **결과 피드백 철저:** 발송 성공 시 완료 모달/메시지 표출 및 폼 리셋. 발송 실패 시(메일 서버 에러 등) **절대로 성공 메시지를 띄우지 말고** "발송 중 오류가 발생했습니다. 잠시 후 다시 시도해주시거나 전화/대표메일로 문의 바랍니다." 안내 메시지 표출.

### 4.8 [P-08] 개인정보처리방침 (`/privacy`)
- 문의하기 폼에서 수집하는 정보(성명, 이메일, 소속, 문의내용)의 수집 목적, 보유 및 이용 기간(예: 문의 처리 후 1년 또는 3년), 파기 절차, 이용자의 권리 등을 규정.
- 인터넷에서 임의 복사한 템플릿이 아닌, 실제 사이트 운영 환경에 일치하도록 작성.

## 5. 관리자(Admin) 기능 작업 지시

- **접근 통제:** `/admin` 경로는 일반 네비게이션에 노출되지 않아야 하며, 인증되지 않은 사용자의 접근을 차단.
- **인증 (ADM-01):** 관리자 ID/PW 로그인, 실패 횟수 제한, 일정 시간 미조작 시 자동 세션 만료.
- **게시물 관리 (ADM-02):**
  - 게시물 등록/수정/삭제 (CRUD).
  - 분류 선택: 공지사항, 기관 활동/보도, 학술논문, 원장 대외활동.
  - 메타데이터 필드: 실제 행사/발행일, 출처/DOI 링크, 원본 기사 URL, 대표 썸네일 이미지 업로드.
  - **상태 제어:** `공개` / `비공개` / `임시저장` 토글 스위치.
  - **메인 노출 지정:** `메인 노출(최대 3건)` 체크박스 기능.
  - 보안: 본문 에디터 입력 시 XSS 방지 필터링(Sanitization) 필수 적용.

## 6. 비기능적 요구사항 (NFR) 및 디자인 품질 가이드

1. **반응형 웹 지원:**
   - 브레이크포인트: 모바일(375px~), 태블릿(768px~), 데스크톱(1440px~).
   - 모든 해상도에서 가로 스크롤 잘림, 텍스트 겹침이 없을 것.
   - 모바일 환경에서 햄버거 메뉴 및 터치 타깃(최소 44×44px) 확보.
2. **디자인 톤앤매너:**
   - 공공성·전문성이 느껴지는 차분한 남색(Navy), 블루, 쿨 그레이 계열 적용.
   - 본문 폰트 크기 최소 14px~16px 이상 유지 및 WCAG AA 기준 명암비(최소 4.5:1) 준수.
3. **웹 보안:**
   - HTTPS SSL 보안 프로토콜 기본 적용.
   - 관리자 비밀번호 단방향 암호화(bcrypt/argon2).
   - 문의 폼 및 관리자 입력창의 SQL Injection 및 XSS 공격 방어.
4. **검색엔진 최적화 (SEO):**
   - 페이지별 고유 `<title>` 및 `<meta name="description">` 설정.
   - Open Graph (og:title, og:image, og:description) 메타태그 구성.
   - 검색엔진용 `sitemap.xml`, `robots.txt` 설정.

## 7. 인수검수 체크리스트 (Acceptance Criteria, AC-01 ~ AC-15)

본 프로젝트의 완료 검수는 다음 15개 항목을 모두 통과해야 최종 승인됩니다.

- [ ] **AC-01 (네비게이션):** 4개 GNB(진흥원 소개, 주요사업, 소식·성과, 문의하기)와 홈 로고가 PC/모바일에서 정상 동작하는가?
- [ ] **AC-02 (페이지 완전성):** 7개 고정 페이지와 게시물 상세 템플릿이 URL 직접 접속 및 새로고침 시 오류 없이 렌더링되는가?
- [ ] **AC-03 (구조 일치):** 사이트맵, 와이어프레임 및 실제 메뉴 라우팅이 기획안 v3.0과 1:1로 정확히 일치하는가?
- [ ] **AC-04 (사업 안내 및 자격증 분리):** 4개 주요사업이 올바르게 소개되어 있으며, 민간자격에 '준비'가 명기되고 시험 접수/발급 기능이 완전히 배제되었는가?
- [ ] **AC-05 (인물/기관 실적 분리):** 원장 개인의 경력·논문·수상과 진흥원 자체의 수행 실적이 오해 없이 엄격히 분리 표기되었는가?
- [ ] **AC-06 (통합 게시판):** 1개의 게시판에서 4개 유형 필터링, 검색(선택), 페이지네이션, 상세 보기가 정상 작동하는가?
- [ ] **AC-07 (관리자 CRUD):** 관리자가 글을 등록, 수정, 삭제, 비공개 처리하고 메인 노출(최대 3건)을 설정할 수 있는가?
- [ ] **AC-08 (비공개 통제):** 비공개 또는 삭제된 게시글이 메인 화면 및 상세 URL 직접 접근 시 완벽히 차단되는가?
- [ ] **AC-09 (문의 전송 신뢰성):** 문의 양식 작성 후 실제 지정된 관리자 메일로 수신되며, 발송 실패 시 거짓 성공 메시지를 띄우지 않는가?
- [ ] **AC-10 (개인정보 보호):** 문의하기 폼의 개인정보 수집 고지 내용과 실제 저장/전송 데이터 항목이 일치하는가?
- [ ] **AC-11 (정관 보안):** 다운로드/열람 가능한 공개용 정관 PDF에서 임원진/회원 개인정보 및 서명이 완벽히 제거되었는가?
- [ ] **AC-12 (허위 정보 배제):** 미래스마트산업연구소의 사업자번호, 미확정 등록번호, 가상 통계 등이 일체 노출되지 않는가?
- [ ] **AC-13 (저작권 준수):** 등록된 모든 논문/기사 링크가 유효하며, 무단 복제된 언론사 사진이나 기사 전문이 없는가?
- [ ] **AC-14 (반응형 및 접근성):** 모바일(375px), 태블릿(768px), PC(1440px) 환경에서 깨짐 없이 렌더링되며 키보드 네비게이션이 가능한가?
- [ ] **AC-15 (최종 인계):** 도메인, 서버 호스팅 계정, 관리자 계정, 소스코드 저장소, DB 백업/복구 매뉴얼이 발주자에게 정상 인계되었는가?
